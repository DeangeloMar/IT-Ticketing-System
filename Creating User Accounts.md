   <h1>Provisioning User Accounts</h1>

<h2>Description</h2>
Step-by-step guide for provisioning help desk user accounts, including assignment group setup for basic ticketing access.
<br />

<h2>Account Setup</h2>

<p>
Using an admin account, on the homepage navigate to organizations then Users. on the top right you will be prompted to create a new account, selecet then create a new personal user account, and populate the required fields with the appropriate account credentials.<br/>
