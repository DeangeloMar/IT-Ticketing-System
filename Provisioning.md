   <h1>Provisioning User Accounts</h1>

<h2>Description</h2>
Step-by-step guide for provisioning help desk user accounts, including assignment group setup for basic ticketing access.
<br />

<h2>Account Setup</h2>

<p>
Using an admin account, navigate to Organizations > Users from the homepage:<br/>
<img width="1918" height="909" alt="servicenow_users_arrow" src="https://github.com/user-attachments/assets/d4d8c251-6c1c-4f61-a3a0-5192abbd59bc" />
<br />
<br />
In the top right, click New to create a user account:<br/>
<img width="1919" height="910" alt="image" src="https://github.com/user-attachments/assets/c406137e-3757-4edc-a2fe-2cb2562ddc85" />
<br />
<br />
Populate the required fields with the appropriate account credentials, then select Submit:<br/>
<img width="1918" height="910" alt="image" src="https://github.com/user-attachments/assets/d6612f0b-64e2-45a6-93e4-71c2c57ab136" />
<br />
<br />
Go back to the list of users and select the account you just created. There's a new section at the bottom of the page — select Groups > Edit:<br/>
<img width="1917" height="911" alt="image" src="https://github.com/user-attachments/assets/7cbd6ae0-07d8-44d5-a799-8c86aa880c98" />
<br />
<br />
assign the newly created account to an assignment group (Help Desk), which grants access to the roles assigned to that group For the account, this allows it to have basic help desk functionality.<br/>
